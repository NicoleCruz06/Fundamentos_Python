# Lista 4: Fundamentos do Comando `for` em Python

Esta pasta contém a minha resolução para a lista de exercícios focada na estrutura de repetição **`for`**.

Diferente do `while`, o laço `for` em Python é especialista em **iteração**. Pratiquei como percorrer sequências numéricas e coleções de dados de forma controlada, sabendo exatamente (ou delimitando) quantas vezes o bloco deve se repetir.

## Conceitos Praticados
* **Iteração com a Função `range()`:** Uso de limites iniciais, finais e passos (`range(start, stop, step)`) para criar loops numéricos precisos.
* **Iteração sobre Sequências:** Percorrer strings e listas elemento por elemento diretamente com o `for`.
* **Análise de Dados em Loops:** Identificação de valores máximos, mínimos, médias e filtragens no decorrer de uma repetição.
* **Loops Aninhados:** Estruturação de um laço `for` dentro de outro para problemas bidimensionais ou matrizes simples.
