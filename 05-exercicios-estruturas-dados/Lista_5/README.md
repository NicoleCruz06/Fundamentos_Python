## Conceitos Praticados
* **Listas (`list`):** Criação, indexação, fatiamento (*slicing*) e métodos de manipulação como `.append()`, `.insert()`, `.pop()` e `.sort()`.
* **Tuplas (`tuple`):** Entendimento e aplicação de coleções ordenadas e **imutáveis**, ideais para segurança de dados.
* **Dicionários (`dict`):** Armazenamento de dados no formato de Chave-Valor, facilitando buscas rápidas e mapeamento estruturado de informações.
* **Conjuntos (`set`):** Manipulação de coleções de elementos únicos (sem duplicatas) e operações matemáticas de conjuntos (união, interseção).
