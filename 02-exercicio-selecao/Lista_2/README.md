# Lista 2: Fundamentos de Comandos de Seleção em Python

Esta pasta contém a minha resolução para a lista de exercícios focada em **Comandos de Seleção (Estruturas Condicionais)**.

Aqui, o código deixa de ser puramente linear e passa a "tomar decisões". Aprendi a fazer o programa desviar seu caminho e executar blocos de código específicos dependendo se uma condição é verdadeira ou falsa.

---

## Conceitos Praticados
* **Estruturas Condicionais:** Uso dos comandos `if`, `elif` e `else` para criar desvios no fluxo do programa.
* **Operadores Relacionais:** Comparações lógicas usando igualdade (`==`), diferença (`!=`), maior/menor que (`>`, `<`), e maior ou igual/menor ou igual (`>=`, `<=`).
* **Operadores Lógicos:** Combinação de múltiplas condições usando os operadores booleanos `and` (e), `or` (ou) e `not` (não).
* **Validação de Dados:** Criação de regras de negócio simples para evitar erros ou entradas inválidas.
