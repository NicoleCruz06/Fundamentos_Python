A modularização é um dos hábitos mais importantes de uma boa desenvolvedora. Aqui, pratiquei como quebrar problemas grandes em blocos de códigos menores, nomeados, organizados, fáceis de testar e, acima de tudo, **reutilizáveis**.

## Conceitos Praticados
* **Definição de Funções:** Uso da palavra-chave `def` para isolar e nomear blocos de lógica.
* **Parâmetros e Argumentos:** Passagem de informações obrigatórias e valores padrão (*default arguments*) para dentro das funções.
* **Retorno de Valores:** Uso do comando `return` para enviar o resultado gerado pela função de volta para o programa principal.
* **Escopo de Variáveis:** Compreensão da diferença prática entre variáveis globais e variáveis locais.
