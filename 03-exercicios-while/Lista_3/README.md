# Lista 3: Fundamentos do Comando `while` em Python

Esta pasta contém a minha resolução para a lista de exercícios focada na estrutura de repetição **`while`**.

O laço `while` (enquanto) é a minha introdução ao conceito de loops baseados em condições. Pratiquei como repetir um bloco de código um número indeterminado de vezes, até que uma condição específica deixe de ser verdadeira.

## Conceitos Praticados
* **Loops Baseados em Condições:** Implementação do comando `while` para repetições dinâmicas.
* **Contadores e Acumuladores:** Uso de variáveis para contar ocorrências (`i += 1`) ou somar valores progressivamente (`soma += valor`).
* **Controle de Loop:** Uso do comando `break` para interromper o laço abruptamente e `continue` para pular para a próxima iteração.
* **Menus Interativos:** Criação de programas que continuam rodando até que o usuário decida digitar uma opção de saída (ex: "Digite 0 para sair").
