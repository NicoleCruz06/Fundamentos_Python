# 🐍 Projetos de Iniciação em Python

Bem-vindo(a) à minha pasta de estudos dedicada aos **fundamentos e primeiros projetos na linguagem Python**.

Este espaço funciona como o meu laboratório de programação. Aqui estão concentrados os códigos que desenvolvi para consolidar minha base em lógica de programação, estruturas de dados e algoritmos. Cada pasta representa um degrau na construção do raciocínio lógico necessário para o desenvolvimento de soluções robustas em Ciência de Dados e Políticas Públicas.

---

## O que estou praticando por aqui?

Os projetos e scripts desta pasta foram construídos para dominar os pilares essenciais do Python:

* **Lógica e Controle:** Estruturas condicionais (`if/elif/else`) e laços de repetição (`for/while`).
* **Estruturas de Dados Coletivas:** Manipulação eficiente de Listas, Dicionários, Tuplas e Conjuntos.
* **Modularização:** Criação de funções personalizadas e tratamento de exceções/erros (`try/except`).
* **Automação Básica:** Manipulação de arquivos externos (leitura e escrita de arquivos `.txt` e `.csv`).
