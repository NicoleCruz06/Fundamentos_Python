# Lista 1: Fundamentos de Comandos de Sequência em Python

Esta pasta contém a minha resolução para a lista de exercícios focada em **Comandos de Sequência**.

Os algoritmos sequenciais são a base de qualquer programa. Aqui, pratiquei a lógica mais pura do desenvolvimento de software: instruções que são executadas passo a passo, de cima para baixo, em uma ordem linear e previsível.

---

## Conceitos Praticados
* **Variáveis e Tipos de Dados:** Criação de variáveis e entendimento de tipos como strings, inteiros (`int`) e números decimais (`float`).
* **Interação com o Usuário:** Entrada de dados usando o comando `input()` e saída formatada com `print()`.
* **Operadores Aritméticos:** Operações matemáticas básicas (soma, subtração, multiplicação, divisão, resto da divisão `%` e divisão inteira `//`).
* **Formatação de Strings:** Uso de f-strings para exibir resultados de forma elegante e legível.
